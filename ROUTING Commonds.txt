ACL 
```
Standard - On destination Router (3rd Router)

access-list 10 deny host x.x.x.x(source ip individual one pc) 
access-list 10 permit any 
int fa 0/0
ip access-group 10 out


Extendard - On source Router (1st Router)

access-list 100 deny tcp host x.x.x.x (source ip individual one pc) host x.x.x.x (destination int fa 0/0 of 3rd router) eq telnet 

access-list 100 permit ip any any

int fa 0/0
ip access-group 100 in

Dynamic NAT - On 1st Router
``````````` 

access-list 10 permit 192.168.x.0 0.0.0.255
ip nat pool ditiss 10.0.0.4 10.0.0.6 netmask 255.0.0.0
ip nat inside source list 10 pool ditiss
int fa 0/0
ip nat inside 
int se 1/0
ip nat outside
